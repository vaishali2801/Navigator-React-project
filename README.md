🧭 Navigator - React Router Project

A simple React Navigation Application built to understand and practice client-side routing using React Router DOM. This project demonstrates how multiple pages can be connected and navigated without reloading the browser.

📖 About the Project

Navigator is a beginner-friendly React project created to learn the fundamentals of React Router DOM.

The project demonstrates how to create different routes for different pages and navigate between them using React Router. It helps in understanding how Single Page Applications (SPAs) handle navigation on the frontend.

✨ Features
🧭 Client-side navigation

📄 Multiple pages using React components

Installation

Clone the repository:

git clone https://github.com/vaishali2801/Navigator-React-project.git

Go to the project directory:

cd navigator

Install the required dependencies:

npm install

Install React Router DOM:

npm install react-router-dom

Start the development server:

npm run dev

Open the application in your browser using the local URL provided by Vite.

🧭 How Navigation Works

The application follows a simple routing flow:

User
  ↓
Navigation Link
  ↓
React Router
  ↓
URL Path
  ↓
Matching Route
  ↓
React Component
  ↓
Page Displayed

For example:

/       → Home Page
/about  → About Page
/contact → Contact Page

React Router changes the displayed component based on the URL without performing a complete browser page refresh.
